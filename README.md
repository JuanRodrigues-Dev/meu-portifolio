# Portfólio Pessoal - Juan Rodrigues Gomes

Portfólio profissional desenvolvido com React + Vite para apresentar habilidades, projetos e experiência de desenvolvimento de software.

## Sobre o projeto

Este site funciona como cartão de apresentação digital para mostrar:

- formação e especialização
- habilidades técnicas
- projetos relevantes
- links de GitHub e LinkedIn
- currículo para download

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- Framer Motion
- Lucide React
- CSS moderno

## Pré-requisitos

Antes de rodar o projeto, certifique-se de ter instalado:

- Node.js 18+
- npm ou yarn

## Como rodar localmente

```bash
npm install
npm run dev
```

Acesse no navegador:

```bash
http://localhost:5173/
```

## Build para produção

```bash
npm run build
```

## Deploy no GitHub Pages

Este projeto já está configurado para publicação no GitHub Pages usando o pacote `gh-pages`.

1. Crie um repositório público no GitHub.
2. No GitHub, o repositório deve seguir o formato:
   - usuário: `JuanRodrigues-Dev`
   - repositório: `meu-portfolio`
3. Faça o push do projeto para o GitHub.
4. Execute:

```bash
npm run deploy
```

A URL pública ficará assim:

```bash
https://JuanRodrigues-Dev.github.io/meu-portfolio/
```
